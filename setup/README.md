# 설문 폼 연결하기 (5분)

설문 내용을 **메일로 받고 + 구글 시트에 자동 저장**하는 설정입니다.
무료이고, 데이터는 전부 퐈퐈님 구글 계정 안에 쌓입니다.

지금은 연결 전이라 제출 버튼을 누르면 메일 앱이 열립니다.
아래를 끝내면 페이지 안에서 바로 전송됩니다.

---

## 1. 구글 시트 만들기

1. <https://sheets.new> 접속 → 빈 시트가 생깁니다
2. 이름을 `브랜디크 설문` 으로 바꿉니다

## 2. 코드 붙여넣기

3. 그 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
4. 편집기에 있던 `function myFunction() {}` 를 **전부 지우고**,
   같은 폴더의 **`apps-script.gs` 내용을 통째로 붙여넣기**
5. 💾 저장 (⌘S)

## 3. 동작 확인

6. 편집기 위쪽 함수 선택창에서 **`테스트`** 를 고르고 **실행** 클릭
7. 처음 실행하면 권한 요청이 뜹니다:
   - **검토** → 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱입니다" 경고가 나오면
     → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
   - ⚠️ 이 경고는 정상입니다. 남이 만든 앱이 아니라 **퐈퐈님이 방금 만든 스크립트**라서 뜨는 겁니다
8. 시트에 한 줄 들어오고, 메일이 오면 성공입니다

## 4. 배포해서 주소 받기

9. 편집기 오른쪽 위 **배포 → 새 배포**
10. 톱니바퀴 ⚙ → **웹 앱** 선택
11. 설정을 이렇게 맞춥니다:
    - **설명**: 아무거나 (예: 설문 v1)
    - **다음 사용자로 실행**: **나**
    - **액세스 권한이 있는 사용자**: **모든 사용자** ← ⚠️ 꼭 이걸로
12. **배포** → 나오는 **웹 앱 URL** 복사
    (`https://script.google.com/macros/s/AKfy....../exec` 형태)

## 5. 설문 페이지에 붙이기

13. `brandique/survey.html` 을 편집기로 열기
14. 아래쪽 `<script>` 안에서 이 줄을 찾습니다:

```js
const ENDPOINT = '';
```

15. 복사한 주소를 따옴표 안에 넣고 저장:

```js
const ENDPOINT = 'https://script.google.com/macros/s/AKfy....../exec';
```

끝입니다. 이제 설문을 제출하면 **시트에 쌓이고 메일이 옵니다.**

---

## 자주 막히는 지점

| 증상 | 원인 / 해결 |
|---|---|
| 제출해도 시트에 안 들어옴 | 4단계에서 **액세스 권한 = 모든 사용자**가 아닌 경우. 배포를 수정하세요 |
| 코드를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다 |
| 메일이 안 옴 | 스팸함 확인. Gmail 무료 계정은 하루 100통 제한이 있습니다 |
| 권한 경고가 무서움 | 정상입니다. 퐈퐈님 계정에서 퐈퐈님이 만든 스크립트라 검수 대상이 아닙니다 |

## 나중에 바꾸고 싶을 때

- **받는 메일 주소** — `apps-script.gs` 위쪽 `MAIL_TO` 수정 후 재배포
- **문항 추가** — `survey.html` 에 입력칸만 추가하면 시트에 **열이 자동으로 생깁니다**. 백엔드는 손댈 필요 없습니다
- **카카오톡 알림** — 채널 개설 후 알림톡 API를 붙이면 됩니다 (별도 작업)

## 파일 첨부는 아직 안 됩니다

이미지 첨부는 `file://` 로 여는 환경에서 불안정해서 넣지 않았습니다.
대신 설문에 **"참고 자료 링크"** 칸을 넣어 뒀습니다 — 고객이 구글 드라이브·네이버 MYBOX 링크를 남기면 됩니다.
사이트를 `brandique.co.kr` 에 올린 뒤에는 첨부 기능도 추가할 수 있습니다.
